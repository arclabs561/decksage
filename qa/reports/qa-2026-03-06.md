## 9. Actionable Issues (Ordered by Impact)

### P0: Ship-blocking

None.

### P1: Functional gaps

1. **MeiliSearch API key misconfigured.** All text search returns empty. Unchanged from previous runs.

2. **Deck completion underfills (32/60).** English filter reduces candidate pool aggressively. The embedding model includes ~55% non-English names; filtering them out halves the pool. Fix: retrain embeddings on English-only data, or relax filter to allow cards with ASCII-only names.

3. **Fusion mode ~65s.** Unusable. Unchanged. Not retested this run.

### P2: Quality issues

4. **Contextual results have null similarity scores.** The API returns `similarity: null` for all synergy/alternative results. Fix: populate from the underlying score.

5. **Contextual upgrades quality.** Llanowar Elves as an "upgrade" to Lightning Bolt doesn't make game sense. The deck_frequency proxy for "price" produces irrelevant matches. Fix: require same card type or functional overlap for upgrades/downgrades.

6. **Pokemon/YGO contextual sparse.** Pokemon returns 0 synergies, 0 upgrades, 0 downgrades. YGO returns 0 synergies, 0 upgrades. Less co-occurrence data for these games.

7. **Results heading still slightly overlapped.** The accent bar gradient sits close to the "Results" h2 text. Margin increased from 16px to 24px but not fully resolved at all scroll positions.

### P3: Polish

8. **Empty search returns no user-facing hint.** When MeiliSearch auth fails, search returns 200 with 0 results silently.

9. **YGO whitespace at 7/10.** Weakest VLM dimension. Increase padding between card elements.

## 10. Summary

**Fix verification run.** 10 planned fixes from QA 03-05 implemented across 5 commits. **8 of 10 fully verified working**, 1 partial (accent bar overlap), 1 applied but untestable (MeiliSearch key -- service still misconfigured externally).

**Major quality wins this run:**
- **Color identity filtering** eliminates off-color basic lands from suggestions (Forest/Island/Plains/Swamp no longer dominate mono-red recommendations)
- **Meta mode differentiated** from synergy (surfaces format staples vs co-occurrence partners)
- **Non-English names eliminated** from deck completions (0% vs 55%)
- **Frontend rendering fixed**: no more `[object Object]`, correct footer, proper mobile wrapping

**Regression:** Deck completion reaches only 32/60 (was 57/60) due to English-only candidate filtering. The embedding pool contains ~55% non-English card names; filtering them removes more than half the candidates.

**Stability:** All 6 baseline similarity queries return identical results across 11+ runs spanning 4 days. VLM scores stable at 8/8/8. No 500 errors in final run.

**Trajectory:** Quality improving. 8 bugs closed this run, 1 new regression (deck underfill) is a known trade-off of the English filter. Remaining open issues are infrastructure (MeiliSearch auth), performance (fusion), and refinement (contextual quality, heading overlap).
